About Zeal 8-bit Computer emulator

The purpose of this project is to provide an easy way to try Zeal 8-bit Computer, as well as develop and debug for it thanks to the embedded debugger. Zeal-NativeEmulator runs the hardware in WebAssembly. This page provides the browser debugger.

You can find more information about Zeal 8-bit Computer on Youtube or on the project official website zeal8bit.com

Source code

The source code of the emulator is available on the official Github repository: https://github.com/Zeal8bit/Zeal-WebEmulator

Using the browser debugger

Load a ROM

Choose a prebuilt Zeal 8-bit OS image or open Advanced to load a local ROM with an optional EEPROM image and map file. The emulator starts after the image loads. Changes to the images last for the current session.

Click the emulated screen before typing or playing audio.

In Settings, use Mount HostFS to share a folder with a HostFS-enabled ROM. The guest can read and write files in the selected folder.

Control execution

  • F9 pauses or continues execution.
  • F10 executes one instruction while paused.
  • F11 steps over a call while paused.
  • Reset resets the machine and pauses at its entry point. Clean closes the current session.

Set breakpoints

Enter a hexadecimal address or a loaded map symbol and press Enter. Click a disassembly row to add or remove a breakpoint. In the breakpoint list, click the address to enable or disable it, or click × to remove it. Break on VBlank pauses at the next emulated vertical blank.

Inspect memory and video

Click a register address to open the memory viewer at that location. The viewer accepts a hexadecimal logical address and a decimal byte count. Each row displays its physical and logical addresses. While paused, edit a byte and press Enter to write it.

Open Video to inspect the palette, font, tileset, sprites, and tilemap layers. Choose which panels to show, then use Dump to refresh the previews.
