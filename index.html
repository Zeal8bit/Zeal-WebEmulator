About Zeal 8-bit Computer emulator

The purpose of this project is to provide an easy way to try Zeal 8-bit Computer, as well as develop and debug for it thanks to the embedded debugger. Zeal-NativeEmulator runs the hardware in WebAssembly. This page provides the browser debugger.

You can find more information about Zeal 8-bit Computer on Youtube or on the project official website zeal8bit.com

Source code

The source code of the emulator is available on the official Github repository: https://github.com/Zeal8bit/Zeal-WebEmulator

Using the browser debugger

Load a ROM

The emulator boots the latest available Zeal 8-bit OS release by default. Open Web Settings to choose another release or use Load local files to load a ROM with an optional EEPROM image and map file. Changes to the images last for the current session.

Click the emulated screen before typing or playing audio.

In Web Settings, use Mount HostFS to share a folder with a HostFS-enabled ROM. The guest can read and write files in the selected folder.

Control execution

  • F9 pauses or continues execution.
  • F10 executes one instruction while paused.
  • F11 steps over a call while paused.
  • Reset resets the machine and pauses at its entry point. Close session in Web Settings unloads the current session.

Set breakpoints

Enter a hexadecimal address or a loaded map symbol and choose Exec, Read, Write, or R/W. Click a disassembly row to add or remove an execution breakpoint. Click a breakpoint in the list to enable or disable it, or click × to remove it. Break on VBlank pauses at the next emulated vertical blank.

Inspect the machine

Click a register, Stack slot, or resolved Watch address to inspect it in Memory. Read up to 1024 bytes at a time or use Next to advance. While paused, edit a byte and press Enter to write it.

Disassembly shows 48 instructions at a time. Use Load more to extend the view to 192 or enter an address or symbol to jump. Follow PC returns to the current instruction when execution stops.

Watch accepts addresses, symbols, and expressions such as (HL) and (IX+2). CPU, Stack, and the open Memory and Watch views sample once per second while running. Turn sampling off in Web Settings.

Open Video to inspect the palette, font, tileset, sprites, and tilemap layers. Choose which panels to show, then use Dump to refresh the previews.
